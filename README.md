# ITI-Credit-Copilot-Lite

ITI Staff Technical Assessment — Finance Credit Copilot Lite  
Grounded RAG Assistant for Personal Loan Underwriting

## Tech Stack

- Laravel 10
- PHP 8.3
- PostgreSQL 16
- pgvector
- Docker Compose
- Ollama
- OpenAPI / Apidog
- PHPUnit

## Core Features

- Policy document ingestion and semantic retrieval
- Grounded answers with citations
- Refusal when evidence is insufficient
- Policy edition selection
- Applicant data extraction
- Deterministic loan calculations and eligibility rules
- Protected attribute removal
- Human approval workflow
- Evaluation and audit logging
